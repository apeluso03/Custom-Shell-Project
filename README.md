# Custom Shell
This project was done in C to resemble the UNIX command line

## Setup
Open directory in a command line and type "make" to compile all necessary files

## Commands
- EXIT
- WHERE
- WHICH
- CD
- GET_CWD
- PWD
- LIST
- PID
- KILL
- PROMPT
- PRINT_ENV
- SET_ENV
- WATCHUSER
- NOCLOBBER
- command_count
